But du jeu

Compléter chaque case avec un chiffre et une couleur, en respectant tous les indices entre les cases.

Chaque combinaison chiffre + couleur apparaît exactement une fois dans la grille.

31. Indice numérique : somme des deux chiffres.

Les indices sont identiques dans les deux grilles ; seuls les chiffres et les couleurs des cases sont à trouver.

Règles

  • Un indice numérique indique la somme des chiffres des deux cases voisines.
  • Un indice coloré indique le mélange de leurs couleurs : bleu + jaune = vert, bleu + rouge = violet, rouge + jaune = orange.
  • Le blanc est neutre dans un mélange ; le noir l'emporte sur les autres couleurs. Deux couleurs identiques donnent cette même couleur.
  • Un indice entouré de rouge est négatif : la somme ou le mélange indiqué est interdit.
  • Un emplacement sans indice n'impose aucune contrainte.
