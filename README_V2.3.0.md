# Cogit 2.3.0 — version de test
Le profil initial conserve les clés locales et la base IndexedDB de 2.2.2. Les nouveaux profils ont des clés et une base distinctes. Changer de profil recharge la page ; sauvegarder toute partie en cours avant de changer. Les exports/imports restent propres au profil actif, et ne constituent pas une sauvegarde de tous les profils. Le profil de test est sans partage par défaut ; si activé, son pseudo serveur est préfixé [TEST]. Les analyses doivent exclure ces identifiants. Les envois en attente d'un profil inactif reprendront à sa réactivation. La synchronisation multi-appareils n'est pas incluse. Installer le serveur 2.3.0 avant le jeu pour accepter les lots de 50. Ne pas réinitialiser les onglets. Tests navigateur et serveur réels à effectuer avant publication.
